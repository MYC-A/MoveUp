# Prompts

Готовые промпты для будущих сессий.

## Старт новой сессии

```text
Прочитай docs/agent/README.md, CONTEXT.md, BACKLOG.md и SESSION_LOG.md.
Потом кратко скажи, какой сейчас статус проекта, какие есть риски, и предложи следующий конкретный шаг.
Пока не меняй код.
```

## Продолжить активную задачу

```text
Продолжи задачу из docs/agent/tasks/TASK-XXXX-name.md.
Сначала прочитай файл задачи, затем проверь актуальное состояние кода.
Внеси минимальные нужные изменения, обнови файл задачи и SESSION_LOG.md, затем запусти доступную проверку.
```

## Создать новую задачу

```text
Создай новый task-файл по docs/agent/TASK_TEMPLATE.md для проблемы: <описание>.
Заполни контекст, цель, план, затронутые области, критерии приемки и риски.
Код пока не меняй.
```

## Code review

```text
Сделай review текущих изменений.
Сначала покажи найденные проблемы по важности с файлами и строками.
Потом коротко перечисли, что проверил, какие тесты запускал и какие риски остались.
```

## Handoff

```text
Подготовь handoff для следующей сессии:
1. Что было сделано.
2. Какие файлы менялись.
3. Какие команды запускались.
4. Что не проверено.
5. Самый логичный следующий шаг.
Обнови docs/agent/SESSION_LOG.md и активный task-файл.
```

## Помощь с локальным запуском

```text
Помоги запустить проект локально.
Сначала проверь README.md и docs/agent/CONTEXT.md.
Затем проверь, установлены ли нужные инструменты, и запускай backend/Flutter по одному шагу.
Если упираешься в зависимости или сервисы, зафиксируй точную ошибку и предложи минимальное исправление.
```
