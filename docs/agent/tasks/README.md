# Tasks

Здесь лежат конкретные task-файлы.

Новая задача создается копированием `../TASK_TEMPLATE.md` и именуется следующим номером:

```text
TASK-0001-backend-requirements.md
TASK-0002-local-services.md
TASK-0003-flutter-api-config.md
```

Одна задача должна иметь один понятный результат. Если задача затрагивает и backend, и Flutter, помечай ее как `area: api-contract` и явно описывай критерии приемки.
