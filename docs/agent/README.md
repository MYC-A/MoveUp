# Agent Workspace

Эта папка - постоянная рабочая память для долгих сессий по MoveUp.

Цель: новая сессия должна быстро понять проект, продолжить работу и не тратить время на повторное исследование.

## Файлы

- `CONTEXT.md`: карта проекта, архитектура, модули, runtime-допущения.
- `BACKLOG.md`: список задач и найденных технических долгов.
- `SESSION_LOG.md`: хронологический журнал сессий.
- `DECISIONS.md`: принятые долгосрочные решения и причины.
- `PROMPTS.md`: готовые промпты для старта, review и handoff.
- `TASK_TEMPLATE.md`: шаблон нового task-файла.
- `tasks/`: конкретные task-файлы.

## Чеклист старта сессии

1. Прочитать `CONTEXT.md`.
2. Прочитать `BACKLOG.md`.
3. Прочитать последние записи в `SESSION_LOG.md`.
4. Выбрать или создать один task-файл в `tasks/`.
5. Для изменений в коде работать в отдельной ветке задачи.

## Чеклист завершения сессии

1. Обновить активный task-файл: измененные файлы, проверки, открытые вопросы.
2. Добавить короткую запись в `SESSION_LOG.md`.
3. Если появилось долгосрочное решение, добавить его в `DECISIONS.md`.
4. Оставить понятный следующий шаг.

## Имена задач

Task-файлы именуются так:

```text
TASK-0001-short-kebab-title.md
TASK-0002-flutter-api-config.md
TASK-0003-backend-requirements.md
```

Внутри файла указывать область:

```text
area: flutter
area: backend
area: api-contract
area: docs
```
