# Рабочие заметки по MoveUp

Эта папка - краткая память по проекту для будущей работы: где что лежит, как проверять, какие проблемы уже найдены и что было исправлено.

## Файлы

- `project_context.md` - структура проекта, основные зависимости и полезные команды.
- `checks.md` - какие проверки запускались и какой сейчас статус.
- `backlog.md` - слабые места, риски и задачи на потом.
- `recent_changes.md` - что уже было исправлено в последних проходах.

## Важно

Новые секреты и ключи сюда не добавлялись. Запуск Flutter с `--dart-define` уже описан в `docs_project/Запуск flutter.md`.
