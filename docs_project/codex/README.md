# Рабочие заметки по MoveUp

Эта папка - tracked рабочая память по проекту: где что лежит, как проверять, что уже сделано и какие риски остались.

## Читать в начале новой сессии

1. `project_context.md` - актуальная структура, зависимости и команды.
2. `code_map.md` - карта backend/frontend модулей, экранов, сервисов и моделей.
3. `api_contracts.md` - соответствие backend endpoints и Flutter services, плюс контрактные риски.
4. `checks.md` - последние проверки и их результат.
5. `backlog.md` - слабые места и следующие задачи.
6. `recent_changes.md` - что уже было исправлено.
7. `audit_2026-06-01.md` - последний подробный срез состояния.

## Важно

- Новые секреты и ключи сюда не добавляются.
- Запуск Flutter с `--dart-define` описан в `docs_project/Запуск flutter.md` и README.
- Папка `docs/agent/` упоминается в старых заметках как локальная agent-память, но она игнорируется `.gitignore`; tracked заметки лежат здесь.
